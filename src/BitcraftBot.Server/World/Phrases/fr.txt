# Phrases du chat « @gpt » en français (joueurs qui ont le jeu en français : « fr/ » devant le pseudo).
#
# Comment c'est rangé :
#   [theme]          début d'un thème (minuscules, sans espace ni accent)
#   mots: a, b*, c d mots qui font reconnaître le thème dans le message du joueur
#                    « b* » = tout mot qui commence par « b » ; « c d » = les deux mots à la suite
#                    accents et majuscules : pas besoin, ils sont ignorés ; « ? » = point d'interrogation
#   - phrase         une réponse possible ; {nom} = pseudo du joueur
#   # ...            commentaire, ignoré
#
# Le thème choisi = celui dont le plus de mots sont trouvés. Égalité : le plus haut dans ce fichier gagne.
# Aucun mot trouvé : [autre] (tout en bas).
# Les mots de en.txt comptent aussi (un joueur français peut écrire en anglais).
# Règles : phrases courtes (250 caractères au plus avec le pseudo), gentilles, jamais d'allusion à un bot (D-055),
# jamais d'info sur Julien, pas de fausse info précise sur le jeu.
# Ajouter une phrase : une ligne « - ... » sous le thème. Ajouter un thème : un bloc [nom] ici ET dans en.txt.
