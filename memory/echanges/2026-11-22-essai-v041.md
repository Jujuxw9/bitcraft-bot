# Essai v0.4.2 — ce que voit le bot, réglages du jeu (à faire par Julien)

(La v0.4.1 n'a pas été essayée : la v0.4.2 la remplace.)

Lancer `artifacts/release/BitcraftBot-v0.4.2.exe`. Regarder l'onglet **Bot**, carte **ÉCRAN**, ligne **« Je vois »**, et le journal (lignes `[Écran]` et `[Réglages du jeu]`).

1. Bot ouvert, jeu fermé, cliquer sur le bureau : « Bureau de Windows (jeu fermé) ». Cliquer sur Discord : « Autre programme : Discord (jeu fermé) ».
2. Se connecter au serveur, puis lancer BitCraft :
   - écran d'accueil → « Jeu : écran d'accueil » ? **Appuyer sur Num 0** ;
   - écran de connexion → « Jeu : écran de connexion » ? **Num 0** ;
   - chargement → « Jeu : écran de chargement » ;
   - dans le jeu → « Jeu : en jeu ».
3. Réduire le jeu : « Jeu réduit dans la barre des tâches ».
4. Si tu changes les réglages conseillés (Q-026) dans le menu du jeu : au prochain démarrage du bot, la ligne « [Réglages du jeu] » doit dire 10 sur 10.
5. Carte CAMÉRA : « Oublier les clics » (les anciens ne servent plus).

À me dire : les lignes fausses. Si une ligne dit « écran inconnu », le journal contient le texte lu : c'est ce qu'il me faut.
