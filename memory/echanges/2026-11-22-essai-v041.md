# Essai v0.4.1 — ce que voit le bot (à faire par Julien)

Lancer `artifacts/release/BitcraftBot-v0.4.1.exe`. Regarder l'onglet **Bot**, carte **ÉCRAN**, ligne **« Je vois »**, et le journal (lignes `[Écran]`).

1. Bot ouvert, jeu fermé, cliquer sur le bureau : « Bureau de Windows (jeu fermé) ». Cliquer sur Discord : « Autre programme : Discord (jeu fermé) ».
2. Se connecter au serveur, puis lancer BitCraft :
   - écran d'accueil → « Jeu : écran d'accueil » ? **Appuyer sur Num 0** ;
   - écran de connexion → « Jeu : écran de connexion » ? **Num 0** ;
   - chargement → « Jeu : écran de chargement » ;
   - dans le jeu → « Jeu : en jeu ».
3. Réduire le jeu : « Jeu réduit dans la barre des tâches ».
4. Caméra : carte CAMÉRA, « Oublier les clics » (les anciens ne servent plus, voir l'analyse). Pas besoin de refaire l'apprentissage maintenant.
