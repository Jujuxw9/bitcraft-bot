# Essai v0.3.20 (à faire par Julien)

Lancer `artifacts/release/BitcraftBot-v0.3.20.exe` (ou le raccourci « BitCraft Bot » du bureau).

1. **Recettes** : chercher « Plank » puis « Stone » : les images apparaissent (quelques objets n'en ont pas sur le site d'images : normal).
2. **Image du jeu** : « Démarrer » dans l'onglet Bot : l'image arrive en moins d'une seconde. Aller dans Recettes, revenir : l'image bouge toujours.
3. **Carte Écran** : plus de ligne « Position ». Seule la cible est encadrée sur l'image.
4. Connexion au serveur comme d'habitude, couper un arbre : lignes `[Tâche] Début / Fin` comme en v0.3.19. Sortir ou ranger un bateau : « sortie d'un véhicule » (sans nom d'arbre).

Journal : `artifacts/release/journaux/v0.3.20/`.
