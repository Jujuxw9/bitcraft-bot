# Essai H1 — à faire par Julien (2026-11-18)

Exe : **`artifacts/v0.3.8/BitcraftBot.exe`** (v0.3.5 et v0.3.6 visaient un ancien monde ; v0.3.8 = v0.3.7 + journaux détaillés). Durée : 10 à 15 minutes. Se mettre dans un endroit sûr.

Astuce : si la connexion est refusée, refaire l'étape A (nouveau code) puis se connecter **dans l'heure**.

## A. Le jeton (une seule fois)
1. **Jeu fermé.** Lancer le bot, onglet **« Serveur (H1) »**.
2. Taper l'e-mail lié au compte BitCraft → **« Recevoir le code par e-mail »**.
3. Copier le code reçu → **« Valider le code »**. Attendu : « Jeton enregistré (chiffré) » en vert.

## B. Lecture en direct, dans le bon ordre
4. Région : **18**. Cliquer **« Se connecter »** (jeu toujours fermé).
5. Attendu : « Lecture en direct. » ; le personnage apparaît, « pas connecté dans le jeu ».
6. **Lancer le jeu** et entrer dans le monde. Attendu : « connecté dans le jeu », position, vie, endurance, faim, arbres proches.
7. Onglet **Supervision** → **« Démarrer »**, puis revenir dans l'onglet Serveur : la ligne « Position écran » se remplit.
8. Marcher un peu : la position et la liste des arbres doivent bouger.
9. Cliquer **« Enregistrer un instantané »**.

## C. Le test de déconnexion
10. Jeu toujours ouvert, cliquer **« Se déconnecter »** dans le bot (répondre Oui).
11. **Le personnage reste-t-il connecté dans le jeu ?** Bouger dans le jeu pour vérifier.
