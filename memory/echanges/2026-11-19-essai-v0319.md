# Essai v0.3.19 (à faire par Julien)

Lancer `artifacts/release/BitcraftBot-v0.3.19.exe` (ou le raccourci « BitCraft Bot » du bureau).

1. **Num 5** dans le jeu : il ne se passe plus rien (pas de ligne « Actions bloquées » dans le journal). Num 0 fait toujours la capture.
2. Connexion comme d'habitude (jeu fermé → Se connecter → lancer le jeu).
3. **Couper un arbre** jusqu'au bout, puis attendre 5 s. Dans le journal (onglet Paramètres) :
   - `[Tâche] Début : récolte « … », Forestry niv. …, à N …, E …` ;
   - `[Tâche] Fin : récolte « … », … s, … coups, Forestry +… XP, objets : +… …`.
   Comparer coups, XP et objets avec ce que montre le jeu.
4. **Fabriquer** quelque chose : une ligne « Début : fabrication » et une ligne « Fin » avec les objets utilisés (−) et gagnés (+).
5. **Passage de niveau** (si possible) : `[Métier] … passe niveau …`.
6. **CPU** : carte Système (Paramètres). Noter le CPU du bot sur l'onglet Bot, puis sur l'onglet Recettes (il doit baisser).
7. Sans serveur, le tableau de bord affiche « — » pour vie, endurance et faim (normal : plus lues à l'écran).

Journal : `artifacts/release/journaux/v0.3.19/`.
