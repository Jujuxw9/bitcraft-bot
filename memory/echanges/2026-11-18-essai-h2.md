# Essai H2 (v0.3.11) — à faire par Julien

Exe : **`artifacts\release\BitcraftBot.exe`** (v0.3.11). Durée : 10 minutes, ou plus si possible.

## A. Connexion (comme d'habitude)
1. **Jeu fermé.** Onglet **« Serveur (H1) »** → **« Se connecter »**.
2. Lancer le jeu, entrer dans le monde.
3. Onglet **Supervision** → **« Démarrer »** (pour que le bot lise l'écran), puis revenir dans l'onglet Serveur.

## B. La carte (carte 4, en bas)
4. Vous êtes le point bleu au centre, nord en haut. **Les arbres de la carte sont-ils placés comme autour de vous dans le jeu ?** (Tourner la caméra pour regarder vers le nord.)
5. Le tableau donne pour chaque arbre : âge, **santé**, distance, direction, position N / E.

## C. L'arbre que vous coupez
6. Cibler un arbre dans le jeu et commencer à le couper.
7. Ligne **« Cible à l'écran »** (rose) : le bot doit afficher le même arbre, avec « même santé : c'est bien lui ». Sur la carte, il est entouré de rose ; dans le tableau, marqué ◎.
8. La santé dans le tableau doit baisser en même temps que la barre du jeu.

## D. Marcher loin
9. Marcher tout droit 15 à 20 cases. Ligne **« Zone lue »** : l'heure doit changer ; la carte se remplit de nouveaux arbres.

## E. Journal
10. Onglet **Journal** : il doit rester collé à la dernière ligne, même quand il est plein. Les 4 cases sont cochées.

## À me renvoyer
- Ce qui est juste ou faux sur la carte (une capture de l'onglet Serveur aide beaucoup).
- Les réponses aux points 4, 7, 8, 9, 10.
- Rien d'autre : je lis le journal moi-même dans `artifacts\release\journaux\v0.3.11\`.
