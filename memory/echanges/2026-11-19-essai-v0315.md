# Essai v0.3.15 — à faire par Julien (2026-11-19)

Exe : **`artifacts\release\BitcraftBot-v0.3.15.exe`** (le nom porte maintenant la version). Durée : 15 minutes.
Cet essai couvre aussi celui de la v0.3.14 (pas encore fait) : voir `2026-11-19-essai-v0314.md` (overlay, Num 5, sac et banques).

## A. Connexion
1. **Jeu fermé.** Onglet « Paramètres » → « Se connecter ». Puis lancer le jeu.

## B. Recettes avec images
2. Onglet « Recettes » : chercher « plank ». Les images apparaissent dans la liste (la première fois, quelques secondes de téléchargement).
3. Passer la souris sur un ingrédient : grande image.

## C. Repas automatique
4. Mettre de la nourriture (ex. poisson grillé) **en premier** dans le sac.
5. Paramètres → carte « 4. Repas automatique » : lire le « prochain aliment » (est-ce bien le bon ?).
6. Cocher « Manger automatiquement ». Revenir dans le jeu, **sans toucher le clavier**.
7. Si le bonus de nourriture est fini, ou la faim sous 30 %, le bot doit manger dans les secondes qui suivent. Regarder l'overlay (ligne « Repas auto »).
8. Appuyer sur Num 5 dans le jeu : la case doit se décocher.
