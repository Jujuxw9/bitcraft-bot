# D-002 — MVP : boucle récolte → banque

- **Statut** : Validée
- **Date** : 2026-11-15
- **Validée par** : Julien
- **Liens** : D-016, D-017, Q-006

## Contexte
Il faut un premier objectif fonctionnel, petit et vérifiable.

## Décision
Le MVP récolte un type de ressource dans une zone, va déposer à la banque quand l'inventaire est plein, en boucle.

## Alternatives écartées
- Commencer par le craft : dépend déjà de la récolte.

## Conséquences
- Exige : détection d'une ressource, lecture de l'inventaire, navigation aller/retour banque.
