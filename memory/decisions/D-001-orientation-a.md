# D-001 — Orientation A : bot sur le serveur officiel

- **Statut** : Validée
- **Date** : 2026-11-15
- **Validée par** : Julien
- **Liens** : Q-005, Q-007

## Contexte
Trois orientations possibles : A (serveur officiel, vision + clavier/souris), B (serveur local monté à partir de BitCraftPublic), C (copilote en lecture seule).

## Décision
Orientation A : bot sur le serveur officiel, par vision écran + clavier/souris, avec le compte principal de Julien. Risque accepté (voir [regles-et-risques.md](../00-contexte/regles-et-risques.md)).

## Alternatives écartées
- B (serveur local) : pas le vrai jeu, client non publié.
- C (copilote en lecture seule) : ne répond pas au but (agent qui agit).

## Conséquences
- Risque de sanction ou de bannissement du compte principal.
- Interdits non négociables : pas d'exploit, pas de modification du client, pas de lecture mémoire, pas d'injection, pas de client tiers.
