# Q-013 — Quel « bois » le bot doit-il ramener : écorce, troncs, ou les deux ?
- **Statut** : Ouverte
- **Priorité** : Haute
- **Créée le** : 2026-11-16
## Question
Couper un arbre donne deux choses (lot 3 de captures) :
- **Rough Tree Bark** (écorce) : objets d'inventaire, gagnés pendant la coupe ;
- **Rough Wood Trunk** (tronc) : cargaison lourde qui tombe dans un sac au sol quand l'arbre tombe, et ralentit le personnage.

Lequel compte pour le MVP (D-002, D-021) ?
## Pistes / options
- **A. Écorce seulement** : le bot coupe, laisse les troncs, va à la Banque quand l'inventaire est plein. Le plus simple.
- **B. Écorce + troncs** : le bot ramasse le tronc (Claim All) et le porte à la Banque, un trajet lent par tronc. **À vérifier** : la Banque accepte-t-elle les troncs ?
- **C. Troncs en priorité** : plus de valeur, sans doute, mais plus de trajets.
## Ce qui bloque
Choix de Julien. Proposition Claude : **A pour le MVP**, puis B ensuite.
